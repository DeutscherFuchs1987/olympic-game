# Деплой на Amvera

Проект — статический SPA-фронтенд. Amvera собирает `dist` через `npm run build`
и раздаёт его через nginx (`static_web`). Никакой backend/Node-сервер в рантайме
не нужен.

Актуальный исходный код сейчас лежит в каталоге [`source/`](./source):
коллега ведёт работу в этой папке, а корень репозитория хранит старую копию.
Amvera собирает именно `source/`.

Конфигурация лежит в [`amvera.yaml`](./amvera.yaml):

```yaml
meta:
  environment: static_web
  toolchain:
    name: npm
    version: "22"

build:
  additionalCommands: "npm --prefix source ci && npm --prefix source run build"
  artifacts:
    "source/dist/*": /
```

## 1. Создать проект

1. В [личном кабинете Amvera](https://cloud.amvera.ru) создать проект типа
   **Приложение**.
2. Регион: **Москва** (или Варшава/Майами, если аудитория за рубежом).
3. Тариф:
   - **Начальный** (0,25 vCPU / 500 МБ) — рекомендуется на время первой сборки,
     чтобы Vite гарантированно собрался;
   - после успешного деплоя можно переключить проект на **Пробный**
     (0,1 vCPU / 100 МБ) — nginx легко раздаёт эти файлы.
4. Во вкладке «Конфигурация» проверить, что используется `amvera.yaml` из
   корня репозитория.

## 2. Подключить репозиторий

Репозиторий проекта на Amvera:

```bash
git remote add amvera https://git.msk1.amvera.ru/deutscherfuchs/olympic-game
git push amvera main:master
```

Amvera слушает ветку `master`. Если в удалённом репозитории уже есть
`master`, сначала сделайте `git pull amvera master --allow-unrelated-histories`
или запушьте поверх после согласования истории.

При первом push Git запросит логин/пароль Amvera (или personal access token).

## 3. Домен и SSL

Во вкладке «Домены» проекта можно привязать свой домен или использовать
бесплатный домен Amvera. SSL выдаётся бесплатно, в том числе на пробном тарифе.

## 4. Проверка после деплоя

- Живой сайт: https://olympic-game-deutscherfuchs.msk1.amvera.tech/
- Главная страница открывается, прелоадер проходит.
- Текстура Земли и границы стран загружаются (пути `/textures/...` и
  `/data/...` работают, потому что сайт раздаётся с корня домена).
- Медальный зачёт открывается кнопкой «Медали» под талисманами на телефоне.
- Автопроигрывание таймлайна и карточки Игр работают.

## 5. Обновления

```bash
git push origin main
git push amvera main:master
```

Каждый push в `master` Amvera автоматически пересобирает проект.

> После изменения кода в `source/` сначала проверьте сборку локально:
>
> ```bash
> cd source
> npm ci
> npm run build
> ```

## 6. Если сборка не проходит на Пробном тарифе

Скорее всего, не хватило 100 МБ RAM на `npm install` + `vite build`.
Варианты:

1. Переключить проект на **Начальный** на время сборки, затем вернуть
   **Пробный**.
2. Собрать локально и задеплоить готовые файлы:

```bash
cd source
npm ci
npm run build
```

Затем загрузить содержимое `source/dist/` в проект через интерфейс Amvera и
использовать конфигурацию с `toolchain: html` и `artifacts: "site/*": /`
(файлы `dist` нужно положить в папку `site`).

## 7. После показа

Остановить проект в кабинете Amvera — биллинг прекратится. Amvera удаляет
артефакты остановленного проекта через 30 дней, поэтому исходники и `dist`
лучше сохранить в Git.
