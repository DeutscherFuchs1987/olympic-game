# Olympic Games — Interactive History

Интерактивная 3D-сцена об истории Олимпийских игр 1896–2028: глобус, путешествие по времени, эпохи, карта мира и медальные созвездия.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Что внутри

- **Глобус и плоская карта** — один и тот же набор lat/lon в двух проекциях; кнопка «Карта / Глобус» плавно разворачивает сферу в эквиректангулярную карту.
- **Время как история** — маршруты и города раскрываются по мере движения таймлайна; будущие Игры показаны призрачными кольцами.
- **Эпохи** — сепия и кинохроника, «кодахром», ТВ-скан-линии и цифровой вид; сильный фильтр включается только на момент появления плашки-главы.
- **Олимпийский огонь** — летит по активной дуге между городами и следует за разворотом карты.
- **Медальное созвездие** — при выборе Игр город соединяется дугами с топ-5 странами медального зачёта.
- **Отменённые Игры** — 1916, 1940 и 1944 отмечены призрачными маркерами и короткими историческими плашками.
- **Карточка Игр** — фото, факт, талисман, медальный зачёт, статья и галерея; скролл карточки не управляет временем.

## Управление

- перетаскивание — вращение глобуса;
- клик по маркеру — выбор Игр и подсветка границ страны;
- скролл — движение по времени;
- клик по ленте эпох — переход к началу периода;
- кнопка «Карта» — плоская карта мира;
- `Esc` — закрыть карточку;
- кнопка звука — эмбиент, меняющийся по эпохам.

## Стек

React 19, Vite, React Three Fiber, Three.js, Drei, GSAP, Motion, Tone.js.
